# skin — デザインの原本と、差し替えるときの約束

ここに入っているのが**デザインの原本**。アプリ本体はこれを取り込んだ状態になっている。

| ファイル | 中身 |
|---|---|
| `monster.svg` | 怪獣（目4種・口3種・zzz・ほっぺ）。820×1180pt のスタイルガイド座標系 |
| `money.svg` | お金5種の `<symbol>`（id は `m-bill1000` / `m-coin500` / `m-coin100` / `m-coin50` / `m-coin10`）|
| `skin.delivered.css` | 受け取ったままの skin.css（取り込み前の原本。参照用）|

アプリに入っている場所は次の3か所だけ。`js/` と `css/base.css` は原則さわらない。

1. `css/skin.css` … 色・形・影・文字サイズ
2. `index.html` の `<!-- ===== SKIN: おかねのイラスト ===== -->` ブロック（`money.svg` の中身）
3. `index.html` の `<!-- ===== SKIN: かいじゅう ===== -->` ブロック（`monster.svg` を分解して配置）

---

## 取り込みのときに直した点（次のデザインでも同じ調整が要る）

- **`<symbol>` の id** … `bill` → `m-bill1000`、`c500` → `m-coin500` のようにリネーム。
  JS が `<use href="#m-○○">` で参照する。
- **5円玉・1円玉は受領物に含まれていなかった**ので、同じ作法（外周に濃い色のふち＋
  飾りリング＋数字と「えん」）でこちら側で追加した。次の発注では最初から7種そろえてもらうこと。
- **硬貨の色は本物に合わせた**（受領時は 500=黄、100=青、50=緑、5=ピンク だった）。
  幼児が手元の実物と結びつけやすいことを優先したユーザーの判断。
  500・100・50・1 は銀系で色では見分けられないので、
  **大きさ・数字・ふちの飾り**（500=ギザギザ / 100=点線 / 50=穴 / 1=二重リング）で判別する。
  5円（黄銅＝金）と10円（青銅＝銅）も色味が近いので、穴の有無と大きさで見分ける。
  銀どうしは濃淡をわずかに変え（`--km-c500` → `--km-c1` の順に明るく）、
  飾りリングは白ではなくふちの色にして銀の上でも見えるようにしてある。
- **行のまとめ方** … モックは「金種ごとに1行」だったが、1円・5円が入るとまとめるモードが
  最大6行になり、こまかいモードより縦に伸びる逆転が起きるため、**位ごとに1行**にしている
  （百の位の行に500円玉と100円玉が並ぶ）。
- **状態の持ち方** … 受け取った CSS は `#monster[data-state]` / `data-mode="komakai|matomeru"` だったが、
  アプリ側の契約は **`<body>` の `data-state` / `data-mode="fine|coarse"`**。セレクタを書き換えた。
- **寸法** … `--km-key-size: 98px` のような px 直書きを、すべて `calc(N * var(--mm))` に換算した
  （`98px ÷ 5.25 = 18.7mm`）。px のままだと iPad の機種が変わると実寸がずれる。
- **怪獣を1枚のSVGにしない** … 受け取った `monster.svg` は 820×1180 固定の1枚絵。
  どのiPadでも成立させるため、目・口・ほっぺ・zzz をそれぞれ独立した要素に分け、
  口の中のトレイは **HTMLの `#tray`**（JSが実寸でお金を置く）にしてある。
- **フォント** … `@import` をやめ、`<link>` 1本 ＋ ヒラギノ丸ゴへのフォールバックにした（オフライン対応）。

## 必ず残すID

| ID | 役割 | 外すとどうなるか |
|---|---|---|
| `#monster` | 怪獣全体。`#controls` の上に積む縦フレックスの子 | レイアウトが崩れる |
| `#eyes` | 目の行。ここへの click が `.eye` に当たるとモードが切り替わる | モード切替ができない |
| `.eye` ×2 | 目（`<button>`）。中のSVGに4状態のグループを持つ | 同上 |
| `.eye-open--fine` / `.eye-open--coarse` / `.eye-closed` / `.eye-spiral` | 目の4状態 | 状態が出ない |
| `#mode-label` | こまかい / まとめる の表示 | モード名が出ない |
| `#mouth` | あいた口。`transform: scaleY()` で開閉するので**別のtransformを足さない** | 口が開閉しない |
| `#mouth-inner` | 口の中。`overflow:hidden` を保つ | お金が口からはみ出す |
| `#tray` | **お金を置く矩形**。中身はJSが毎回書き換える | お金が出ない／実寸がずれる |
| `#teeth` | 口の上側の歯。高さ 7.6mm（`js/monster.js` の `TEETH_MM` と一致させる）| トレイの位置がずれる |
| `#mouth-text` `#sparkles` | 「おかいけい ありがとう」ときらきら | お礼が出ない |
| `#mouth-closed-art` `#mouth-chew-art` `#munch` | ねている口 / もぐもぐの口 / 「むしゃむしゃ」 | その状態の絵が出ない |
| `#zzz` | 寝ているときの表示 | zzzが出ない |
| `#controls` `#keypad` `#amount` `#amount-value` `#amount-unit` `#ok` | 下のコントロール | 入力できない |
| `.key[data-key]` | テンキー。`data-key` は `0`〜`9` / `back` / `clear` | そのキーが効かない |
| `#corner-hotspot` `#calibrate` ほか `cal-*` | 較正画面 | 実寸合わせができない |

## 必ず残すお金のSVGシンボル

| id | viewBox の縦横比 | 実寸 |
|---|---|---|
| `#m-bill1000` | 1500 : 760 | 150 × 76 mm |
| `#m-coin500` | 正方形 | φ26.5 mm |
| `#m-coin100` | 正方形 | φ22.6 mm |
| `#m-coin50` | 正方形（中央に穴） | φ21.0 mm（穴 φ4.0 mm） |
| `#m-coin10` | 正方形 | φ23.5 mm |
| `#m-coin5` | 正方形（中央に穴） | φ22.0 mm（穴 φ5.0 mm） |
| `#m-coin1` | 正方形 | φ20.0 mm |

**寸法は `js/layout.js` の `SIZE_MM` が持っていて、絵は必ずその枠いっぱいに描かれる。**
viewBox の縦横比だけ合っていればよく、SVG側で大きさを指定してはいけない。

> ⚠️ **大きさの順は 500 > 10 > 100 > 5 > 50 > 1**（26.5 / 23.5 / 22.6 / 22.0 / 21.0 / 20.0 mm）。
> 額面の順と一致しないのが本物の大小関係であり、
> 「金額感を体で覚える」というこのアプリの目的そのもの。

> ⚠️ **本物の紙幣・硬貨に似せて描かないこと**（通貨及証券模造取締法・紙幣類似証券取締法）。
> 数字と色で区別する、明らかにイラストとわかるデザインにする。印刷もしない。

## 状態（`<body>` の属性）と テンキーの開閉

| 属性 | 値 | 意味 |
|---|---|---|
| `data-state` | `sleep` | 金額0。目を閉じ、口を閉じ、zzz |
| | `input` | 金額入力済み。目を開け、口を開けてお金を並べる |
| | `eating` | OK押下。お金が吸い込まれる（目はぐるぐる）|
| | `thanks` | 食べ終わり。口の中にお礼 |
| `data-chew` | `1` | 咀嚼中。`#mouth` を隠して `#mouth-chew-art` と `#munch` を出す |
| `data-mode` | `fine` / `coarse` | こまかい / まとめる |
| `data-empty` | `1` / `0` | 金額が0かどうか（OKボタンの有効・無効）|
| class `peek` | | 寝ているときに目をタップした瞬間だけ目を開ける |

テンキーは `#controls` の `data-keypad` で切り替える。

| 値 | 高さ | いつ |
|---|---|---|
| `open` | `--controls-open-mm`（107mm）| 金額0のとき／金額欄をタップしたとき |
| `bar` | `--controls-bar-mm`（22mm）| 最後のキーから1.8秒たったら自動で畳む |

## 大きさの決まりごと

- 長さはすべて `calc(N * var(--mm))` で書く。`--mm` は較正後の「1mmのpx数」。
  **`px` 直書きと CSS の `mm` 単位は使わない**（実寸がずれる）。
- flexの子には `min-height: 0` を付ける。付け忘れると中身に押し広げられて高さ指定が効かない。
- **口のトレイの左右に余白を作らない。** 1000円札150mmに対しiPad 10.9インチの画面幅は158mmしかない。
- 幼児が指で押すので、押せる要素は **15mm角以上**（テンキーが `open` のとき）。

## アニメーションの落とし穴（実機で踏んだもの）

- **`animation-fill-mode` に最終状態を依存させない。**
  画面が隠れている（別アプリが前面など）とアニメーションが進まず、`both` だと
  お金やお礼の文字が**出たまま消えない／出てこない**。終わったあとの見た目は
  クラス自身（`.money--in { opacity: 1 }`）が持ち、fill は `backwards` にする。
- **`requestAnimationFrame` を描画のトリガーに使わない。** 画面が隠れている間は呼ばれない。
  要素を作るときにクラスまで付け、ずらす演出は `animation-delay` に任せる。
