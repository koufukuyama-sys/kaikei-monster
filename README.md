# かいけいモンスター

3歳児のままごと用レジ。**画面に出たお金の絵の上に、本物のお金を並べて金額感を体で覚える**ための装置。

```
テンキーで会計金額を打つ
  → 怪獣の口の中に「その金額の払い方」が実寸のお金の絵で並ぶ
    → 子どもが本物のお金をその絵の上に重ねる
      → OK を押すと怪獣がお金を食べて「おかいけい ありがとう」
```

iPad を**机に平置き**して使う前提（硬貨を乗せるため）。
素のHTML/CSS/JSだけで動く。フレームワーク・ビルド・課金はいっさい無し。

---

## 1. Macで動かす（開発・動作確認）

```bash
./serve.sh          # ポートを変えるなら ./serve.sh 8080
```

- Mac: <http://localhost:8000/>
- **iPad**: 表示される `http://192.168.x.x:8000/` を同じWi-Fiの Safari で開く
- iPad実機が無いときのプレビュー: <http://localhost:8000/test/ipad.html>
  （各iPadの画面サイズ・実寸を再現する。縮尺と「実寸◯◯mm」も表示される）
- ロジックテスト: <http://localhost:8000/test/money.test.html>

停止は `Ctrl-C`。開発用サーバはキャッシュ無効なので、編集してリロードすれば必ず反映される。

## 2. iPadに入れる（常用）

**公開済み: <https://koufukuyama-sys.github.io/kaikei-monster/>**

iPadの Safari でこのURLを開き、**共有ボタン → ホーム画面に追加**。
以後はアイコンから**フルスクリーン・オフライン**で起動する（Service Workerが全ファイルをキャッシュする）。
Macを起動しておく必要はない。

> Service Worker は **HTTPS のときだけ**有効にしてある。ローカル開発（`http://localhost` や
> `http://192.168.x.x`）では、編集したJS/CSSが古いキャッシュに隠れてハマるので意図的に無効。

### 更新を反映する

```bash
git add -A && git commit -m "更新内容" && git push
```

push の1〜2分後に GitHub Pages が再ビルドされる。
**iPad側は Service Worker がキャッシュを持っているので、ホーム画面のアイコンから開き直すと
新しい版に入れ替わる**（1回目の起動は古い版、2回目から新しい版になることがある）。
すぐ反映したいときは `sw.js` の `CACHE` のバージョン（`kaikei-monster-vN`）を上げてから push する。

> 公開リポジトリなのでURLは誰でも見られる。個人情報・認証情報は一切入っていない。

## 3. 最初に一度だけ: 実寸合わせ

CSSの `mm` 単位は実際の寸法と一致しない（iPadは約5.2px/mm、CSS規定は3.78px/mm）ので、
**本物の500円玉で較正する**。

1. 画面の**右上の角を2秒長押し**（幼児が誤って入らないように隠してある）
2. 出てきた丸の上に**本物の500円玉**を置く
3. ぴったり重なるまでスライダーを動かす → 「とじる」

この設定は端末に保存されるので、次からは不要。
未較正のときは右上に小さな点が点滅して知らせる。

## 4. あそびかた

| 操作 | 動き |
|---|---|
| テンキー | 会計金額を入力（**0〜2999円・1円単位**）。「1・2・6・5」で1265円 |
| `⌫` / `C` | ひとつ消す / ぜんぶ消す |
| **目をタップ** | **こまかい ⇄ まとめる** の切り替え（既定は こまかい）。目の黒目が変わり、間のラベルも変わる |
| `OK` | 怪獣がお金を食べる → 「おかいけい ありがとう」 → また眠る |
| 金額0 | 怪獣は目と口を閉じて `zzz`（寝ている） |

**テンキーは自動で畳まれる。** 最後にキーを押してから1.8秒たつと、テンキーが細いバーになって
口が画面いっぱいに広がる（お金を実寸で置くため）。**もう一度打ちたいときは金額欄をタップ**すると戻る。

**こまかい / まとめる**

位ごとに独立して分解する（繰り上がりはしない）。

| 位 | こまかい | まとめる |
|---|---|---|
| 千 | 1000円札（どちらも分解しない） | 同左 |
| 百 | 100円玉だけ | 500円玉 ＋ 100円玉 |
| 十 | 10円玉だけ | 50円玉 ＋ 10円玉 |
| 一 | 1円玉だけ | 5円玉 ＋ 1円玉 |

例: 60円 → こまかい 10円玉6枚 / まとめる 50円玉1枚＋10円玉1枚
　　8円 → こまかい 1円玉8枚 / まとめる 5円玉1枚＋1円玉3枚

お金は**位ごとに1行**に並ぶ（同じ行に500円玉と100円玉が混ざる）。
1行に入りきらないときは枚数を行に均等に割る（9枚なら 5＋4）。

### 幼児がアプリから出られないようにする

iPadの `設定 > アクセシビリティ > アクセスガイド` をオンにして、
アプリ起動中にホームボタン（または電源ボタン）を3回押すと、そのアプリに固定できる。

## 5. 作り変える

### 怪獣の声

```bash
./tools/make_voices.sh      # say -v Kyoko で assets/voice/*.m4a を作り直す
```

パパ・ママの声に差し替えたいときは、同じファイル名（`waai.m4a` / `arigatou.m4a`）の
m4a を `assets/voice/` に置くだけでよい。再生時に少し高くして怪獣っぽくしている。

### フォント

デザイン指定は Google Fonts の **M PLUS Rounded 1c**。`index.html` から読み込んでいるが、
**オフラインのときは端末の「ヒラギノ丸ゴ ProN」に自動で落ちる**（見た目はほぼ同じ丸ゴシック）。
完全にオフラインで指定フォントを使いたい場合は、woff2 をサブセットして `assets/font/` に置き、
`css/skin.css` の `--km-font` を差し替える（その場合は `sw.js` の `ASSETS` にも追加する）。

### 見た目（デザイン）

ロジックと見た目は分離してある。デザインの原本は `skin/` にあり、
**[`skin/README.md`](skin/README.md)** が「差し替えるときに守るべき約束」、
**[`DESIGN_BRIEF.md`](DESIGN_BRIEF.md)** が次に発注するときの指示文。
差し替えるのは次の3か所だけで、JSには触らない。

- `css/skin.css` … 色・形・影・文字サイズ（CSS変数）
- `index.html` の `<!-- SKIN: おかねのイラスト -->` ブロック … お金5種のSVG
- `index.html` の `<!-- SKIN: かいじゅう -->` ブロック … 怪獣のSVG/DOM

### 構文チェック

```bash
./tools/check.sh    # このMacのnodeは壊れている(icu4c)ので JavaScriptCore を使う
```

## 7. 既知の制限

- **入力できるのは4桁＝0〜2999円**（千の位は2まで、ほかの位は9まで）。
- **1000円札は150×76mm**あり、iPad 10.9インチの画面幅158mmをほぼ使い切る。
  そのため口の左右には余白を作っていない。
- 大きい金額では自動で縮む（iPad 10.9インチ・テンキーを畳んだ状態＝トレイ 154×163mm）:

  | 例 | お金の表示倍率 |
  |---|---|
  | 999円 こまかい（27枚） | **実寸（100%）** |
  | 1265円 こまかい（14枚） | **実寸（100%）** |
  | 1999円 まとめる（16枚） | **実寸（100%）** |
  | 2555円 こまかい | 約92% |
  | 2999円 まとめる（17枚） | 約89% |
  | 1999円 こまかい（28枚） | 約73% |
  | 2999円 こまかい（29枚・最大） | 約65% |

  実寸100%で出せるのは **こまかい 1650通り / まとめる 2271通り**（全3000通り中）。
  「まとめる」のほうが枚数が少ないぶん実寸で収まりやすい。

  テンキーが畳まれると口が広がって実寸に戻る。それでも入らないときだけ縮める。
- **iPad mini（8.3インチ）は画面幅が116mmしかなく、1000円札が実寸で入らない**（約73%に縮む）。
  実寸で遊ぶなら10.2インチ以上を使うこと。
- お金の絵は**本物に似せていない**。日本の通貨及証券模造取締法・紙幣類似証券取締法があるため、
  数字と色で区別する明らかなイラストにしてある。**印刷して使わないこと。**
